# koishi-plugin-wj6y3-xiuxian

[![npm](https://img.shields.io/npm/v/koishi-plugin-wj6y3-xiuxian?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-wj6y3-xiuxian)

桐子的修仙遊戲插件 —— 一個功能完整的群聊修仙模擬器。

# 警告!由 1.1.*版 迁移至 1.2.0版及以上時 需自行处里数据庫主键迁移(由 平台用户ID 改為伺服器內部的 跨平台唯一用户ID)

未來版本將統一採用此內部ID作為跨平台支持

> **指令名說明**：本文件中用反引號標示、需要照打的內容（指令名、別名、固定參數值）一律為**簡體**，與機器人實際註冊的指令一致；其餘說明文字為繁體。

## 特性

- 🎮 **建號系統**：隨機靈根（五靈根 ~ 混沌靈根），從江湖好手起步
- 📈 **修煉體系**：閉關 / 出關、雙修、參悟天機、靈石修煉
- ⚡ **突破機制**：普通突破 / 渡厄突破、突破 CD、突破丹（大突破丹單次限定 + 通用突破丹 + 渡厄保底）
- 📖 **學習制功法**：已學功法全部累加加成，神通按品階權重在戰鬥中隨機釋放
- ⛩️ **宗門系統**：創建 / 加入 / 捐獻 / 職位 / 供奉 / 宗門任務 / 貢獻兌換
- 👹 **世界 BOSS**：全服共享，參戰者按傷害分獎勵，最後一擊額外掉落；每週一 0 點若無存活 BOSS 自動生成
- 🏞️ **洞天經營**：開闢洞府、升級靈氣、開墾靈田、種植收穫
- ⚗️ **煉丹系統**：需裝備煉丹爐，主藥 / 輔藥類型匹配，按藥力換算所需株數（冷熱調和暫未啟用）
- 📜 **懸賞令**：每日刷新、隨機接取、到期結算、成功率 / 掉落全隨機
- 🏦 **靈莊（銀行）**：7 級會員，存取靈石吃利息
- 🌀 **秘境探索**：每日 3 次（同日內兩次間隔 1 小時），隨機獲得靈石 / 修為 / 物品 / 受傷
- 🗿 **煉體 + 境界共鳴**：煉體境界與修仙境界共鳴提供全屬性加成
- 🏪 **坊市**：買賣互通，支持每小時自動上架、超時下架、系統回收
- 🎲 **小遊戲**：金銀閣（擲骰賭靈石）、虛神界對決（左輪手槍 PvP）、搶靈石（打劫 PvP）
- 📊 **戰鬥回放**：最近 120 秒內的戰鬥記錄可回顧
- 🔁 **長期養成**：參悟傳承（攻擊修煉）、飛升轉世（靈根重抽）、重入仙途（保留宗門 / 職位）

## 安裝

在 Koishi 插件市場中搜尋 `wj6y3-xiuxian` 並安裝，或在專案根目錄執行 `npm install koishi-plugin-wj6y3-xiuxian`。

## 依賴

### 必需

- `database` —— 插件依賴 Koishi 資料庫服務（MySQL / PostgreSQL / SQLite 等）
- `monetary` —— 靈石（貨幣）服務，為必需服務，未安裝時本插件不會啟動。推薦使用 `@koishijs/plugin-monetary`

### 可選

- `cron` —— 定時任務服務（每小時檢查坊市 / 每日 0 點重置與宗門結算 / 每週一 0 點若無存活世界 BOSS 則自動生成一隻）。未安裝或被停用時自動回退到 `setInterval` 模式；cron 重新啟用（含重載）後會自動重新註冊任務

## 快速上手

1. 讓機器人加入群聊
2. 群內發送 `我要修仙` 建立角色
3. 發送 `修仙签到` 領取靈石
4. 發送 `闭关` 開始修煉，稍後 `出关` 結算修為
5. 修為達到後發送 `突破` 查看突破資訊，再 `直接突破` 或 `渡厄突破`
6. 發送 `帮助` 查看指令列表，或對應子系統幫助（`宗门帮助` / `悬赏令帮助` / `灵庄帮助` / `炼丹帮助` / `炼体帮助` / `洞府帮助` / `秘境帮助` / `世界boss帮助` / `传承帮助`）

## 指令概覽

> **未建號攔截**：需要角色的指令會先檢查玩家是否已建號，未建號時提示先發送 `我要修仙`。幫助類、`修仙排行榜`、`宗门列表`、`坊市查看`、`查看世界boss`、`查看修仙物品` 等不需要角色。

| `wj6y3_xiuxian_plot` | 洞府靈田 |

數值欄位：短數值為整數；氣血 / 真元 / 攻擊 / 戰力 / BOSS 數值 / 靈莊存款 / 坊市價格等為長整數（8 位元組）；修為、宗門貢獻、建設度、宗門靈石池等可能長期累積的數值為雙精度，寫入前一律向下取整。舊資料中的小數會在插件啟動時自動取整。

靜態資料（境界 / 功法 / 丹藥 / 武器等）位於 `data/` 目錄，使用 JSON 檔案維護，擴展新內容只需修改對應 JSON 即可，無需改動程式碼。

## 玩法要點

### 數值顯示

氣血、真元、修為、戰力、攻擊、傷害、靈石、貢獻等大數值在訊息中自動縮寫：小於 1000 原樣顯示，之後依國際單位制前綴 `K / M / G / T / P / E / Z / Y / R / Q` 只顯示最大一檔並保留 1 位小數（如 `9521` → `9.5K`、`52174525` → `52.2M`），達到 1000Q 以上改用科學記號（如 `2.5e33`）。百分比維持原樣；僅影響顯示，不影響存儲與計算。

### 學習制功法

功法 / 輔修 / 神通使用 `使用 <名稱>` 學習，**已學全部累加加成**（非裝備制）。每次使用固定消耗 1 本，學習後不可遺忘。

輔修目前已實裝的效果：氣血加成、傷害加成（計為攻擊加成）、吸血；其餘效果尚未實裝，在 `我的功法` 中顯示為「无加成」。

### 丹藥使用規則

- 每次 `使用` 只服用 1 顆；丹藥不再有每日使用次數限制
- **大突破丹**（如築基丹）：整局限服一次，服用後對**對應下一境界**的突破一直有效（多次失敗仍可繼續用），突破成功後自然失效；`突破` 只會列出境界相符且尚未服用的大突破丹
- **通用突破丹**（如冰心丹）：不限次數，直接加到 `levelUpRate`，突破成功後清零
- **攻擊丹**：每種整局限服 5 次，次數記錄在獨立的 `pill_limit` 表中（上架 / 下架等移出背包的操作不會重置次數）
- **修為丹 / 回復丹**：不限次數
- **渡厄丹**：僅在 `渡厄突破` 指令中自動消耗，失敗不扣修為
- 大突破丹與攻擊丹的服用記錄在 **飛升轉世 / 重入仙途** 時重置

### 戰鬥神通

戰鬥中，普攻（權重 200）與已學神通共同組成動作池，每次行動按權重隨機選擇**一種**，不會同時執行。神通釋放消耗 `mpCost × maxmp`，命中按 `rate` 判定；施放後有 `turnCost − 1` 個回合不可再次施放（`turnCost ≤ 1` 即無冷卻），增減益與持續傷害的持續回合數同樣由 `turnCost` 決定。持續傷害（type 2）首擊即時結算，後續回合按施加者實時狀態重算。

### 減傷公式

最終減傷% = 原減傷 + 原減傷 × 練體加乘% + 原減傷 × 防具加乘% + 原減傷 × 生效中的減傷神通增益總和%，上限 100%。

- 原減傷為境界的 `def`；練體與防具的減傷加乘各自獨立計算，均乘以原減傷
- 減傷類神通（增益）在戰鬥中按總和累加，持續期間計入公式
- 怪物 / 世界 BOSS 沿用自身 `def`；穿透與神通攻擊的減傷係數照舊

### 煉丹規則

藥材資料：主藥 `[冷熱, 類型, 藥力]`、藥引 `[冷熱, 類型, 藥力]`、輔藥 `[類型, 藥力]`。丹方需要一種類型相符的主藥與一種類型相符的輔藥（不可為同一種藥材），所需株數 = ⌈丹方所需藥力 ÷ 該藥材的藥力⌉，藥材階數越高藥力越強。冷熱調和機制已保留程式碼，暫未啟用。

### 懸賞令掉落

每次刷新 / 結算自動生成新一批懸賞令時，每條懸賞令有 `bountyDropChance`%（預設 100%）機率附帶 1 ~ `bountyDropCount`（預設 2）件隨機物品。掉落類別權重由 `bountyDropCategoryWeights` 控制，與秘境共用。

### 宗門每日結算

宗門「建設度 → 靈石」結算每天執行一次（0 點定時任務），或由 `我的宗门` / `宗门捐献` / `宗门每日供奉` / `完成宗门任务` 等指令的冪等兜底調用補齊；同一天內重複觸發不會重複結算。
