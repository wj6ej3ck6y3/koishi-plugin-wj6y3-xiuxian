# koishi-plugin-wj6y3-xiuxian

[![npm](https://img.shields.io/npm/v/koishi-plugin-wj6y3-xiuxian?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-wj6y3-xiuxian)

桐子的修仙遊戲插件 —— 一個功能完整的群聊修仙模擬器。

# 警告!由 1.1版本 迁移至 1.2版 时需自行处里数据库主键迁移(由 平台用户ID 改为服务器内部的 跨平台唯一用户ID)

未來版本將統一採用此內部ID作為跨平台支持

## 特性

- 🎮 **建號系統**：隨機靈根（五靈根 ~ 混沌靈根），從江湖好手起步
- 📈 **修煉體系**：閉關 / 出關、雙修、參悟天機、靈石修煉
- ⚡ **突破機制**：普通突破 / 渡厄突破、突破 CD、突破丹（單次限定 + 通用臨時 + 渡厄保底）
- 📖 **學習制功法**：已學功法全部累加加成，神通按品階權重在戰鬥中隨機釋放
- ⛩️ **宗門系統**：創建 / 加入 / 捐獻 / 職位 / 供奉 / 宗門任務 / 貢獻兌換
- 👹 **世界 BOSS**：全服共享，參戰者按傷害分獎勵，最後一擊額外掉落
- 🏞️ **洞天經營**：開闢洞府、升級靈氣、開墾靈田、種植收穫
- ⚗️ **煉丹系統**：需裝備煉丹爐，冷熱調和 + 品級加成
- 📜 **懸賞令**：每日刷新、隨機接取、到期結算、成功率 / 掉落全隨機
- 🏦 **靈莊（銀行）**：7 級會員，存取靈石吃利息
- 🌀 **秘境探索**：每日 3 次、1 小時 CD，隨機獲得靈石 / 修為 / 物品 / 受傷
- 🗿 **煉體 + 境界共鳴**：煉體境界與修仙境界共鳴提供全屬性加成
- 🏪 **坊市**：買賣互通，支持每小時自動上架、超時下架、系統回收
- 🎲 **小遊戲**：金銀閣（擲骰賭靈石）、虛神界對決（左輪手槍 PvP）、搶靈石（打劫 PvP）
- 📊 **戰鬥回放**：最近 120 秒內的戰鬥記錄可回顧
- 🔁 **長期養成**：參悟傳承（攻擊修煉）、飛升轉世（靈根重抽）、重入仙途（保留宗門 / 職位）

## 安裝

在 Koishi 插件市場中搜尋 `wj6y3-xiuxian` 並安裝，或在專案根目錄執行 `npm install koishi-plugin-wj6y3-xiuxian`。

## 依賴

### 必需

- `database` —— 插件依賴 Koishi 資料庫服務（MySQL / PostgreSQL / SQLite 等）
- `monetary` —— 靈石（貨幣）服務，未安裝則靈石相關功能靜默降級。推薦使用 `@koishijs/plugin-monetary`

### 可選

- `cron` —— 定時任務服務。未安裝時自動回退到 `setInterval` 模式（每小時檢查坊市 / 每日 0 點重置）

## 快速上手

1. 讓機器人加入群聊
2. 群內發送 **我要修仙** 建立角色
3. 發送 **修仙簽到** 領取靈石
4. 發送 **閉關** 開始修煉，稍後 **出關** 結算修為
5. 修為達到後發送 **突破** 查看突破資訊，再 **直接突破** 或 **渡厄突破**
6. 發送 **修仙幫助** 或對應子系統幫助（宗門幫助 / 懸賞令幫助 / 靈莊幫助 / 煉丹幫助 / 煉體幫助 / 洞府幫助 / 秘境幫助 / 世界boss幫助 / 傳承幫助）查看完整指令目錄

## 玩法要點

### 學習制功法

功法 / 輔修 / 神通使用 `使用 <名稱>` 學習，**已學全部累加加成**（非裝備制）。學習後書會從背包消耗，不可遺忘。

### 突破丹機制

- **單次限定突破丹**（如築基丹）：整局限服一次，服用後對**對應下一境界**突破永久有效（多次失敗仍可繼續用），突破成功或飛升後自然失效
- **通用突破丹**（如冰心丹）：直接加到 `levelUpRate`，突破成功後清零
- **渡厄丹**：僅在 `渡厄突破` 指令中自動消耗，失敗不扣修為

### 戰鬥神通

戰鬥中，普攻（權重 200）與已學神通共同組成動作池，每次行動按權重隨機選擇**一種**，不會同時執行。神通釋放消耗 `mpCost × maxmp`，命中按 `rate` 判定，效果持續 / 冷卻回合數由 `turnCost` 決定。持續傷害（type 2）首擊即時結算，後續回合按施加者實時狀態重算。

### 懸賞令掉落

每次刷新 / 結算自動生成新一批懸賞令時，每條懸賞令額外掉落 1~2 件隨機物品。掉落類別權重由 `bountyDropCategoryWeights` 控制，與秘境共用。

### 宗門每日結算

宗門「建設度 → 靈石」結算每天 0 點執行一次（cron 模式），或由 `我的宗門` / `宗門捐獻` / `宗門每日供奉` / `完成宗門任務` 等指令的冪等兜底調用補齊。
